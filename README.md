# 零点射击场 · ZEROING RANGE

一个单文件实现的 3D 射击小游戏，全部代码（HTML / CSS / JavaScript）都在 `index.html` 里，无需构建、无外部依赖包，浏览器直接打开即可游玩。

## 运行

- 直接双击打开 `index.html`（推荐 Chrome / Edge / Safari 最新版）
- 或用本地静态服务器：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 说明

- 体量：约 300 KB 单文件，包含内联样式、脚本与素材
- 建议使用桌面端浏览器，配合键盘鼠标操作
